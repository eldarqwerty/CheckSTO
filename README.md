# CheckSTO — Цифровой заказ-наряд, фотосогласование и автовозврат клиентов для СТО Казахстана

**CheckSTO** — готовый к локальному запуску и живой демонстрации на стартап-питче B2B SaaS для независимых автосервисов (на примере СТО в г. Жезказган, область Ұлытау).

## Ключевые возможности
- **Панель мастера СТО (`/`)**: 4 живых KPI-карточки, поиск и фильтрация заказ-нарядов, live-обновление каждые 2 секунды (мгновенная подсветка строки и toast-уведомление, когда клиент согласовывает ремонт со смартфона).
- **ИИ-смета за 3 секунды**: разбор сырой заметки мастера через **Google Gemini API (`gemini-2.5-flash`)** с автоматическим оффлайн fallback-парсером на Python (русский и казахский языки, цены в тенге `₸`).
- **Фотофиксация «ДО» и «ПОСЛЕ»**: загрузка реальных фото или добавление демо-фото в 1 клик.
- **Мобильная страница клиента (`/client/{token}`)**: без регистрации, казахстанский госномер, 4-шаговый прогресс-бар, галерея фото с увеличением, интерактивные чекбоксы рекомендаций с мгновенным пересчётом итоговой суммы, защищённый цифровой чек согласования с датой/временем и **Цифровая сервисная книжка**.
- **Автовозврат ТО**: автоматический расчёт следующего ТО (`+6 мес / +8 000 км`), отправка персонального напоминания в WhatsApp и подсчёт возвращённой выручки.

## Быстрый запуск за 2 команды (macOS / Windows / Linux)

Требуется **Python 3.10+**. Никаких Docker, Node.js или облачных баз данных.

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Запустите сервер
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Откройте в браузере:
- **Панель мастера СТО**: `http://localhost:8000`
- **Пример страницы клиента (Toyota Camry 70 `512 BDA 20`)**: `http://localhost:8000/client/sto-84a2f`

База данных `checksto.db` создаётся автоматически при первом запуске и предзаполняется 4 реалистичными заказами и историей обслуживания.

## Опционально: подключение Google Gemini API

По умолчанию проект работает полностью автономно благодаря встроенному умному парсеру (`ai_parser.py`). Чтобы включить разбор заметок через `gemini-2.5-flash`:
1. Скопируйте `.env.example` в `.env`.
2. Вставьте ваш ключ в `GEMINI_API_KEY=...`.
3. Перезапустите `uvicorn`.

Если ключ не задан или на площадке питча пропадёт интернет, система без единой ошибки переключится на локальный парсер.

## Живое демо на сцене с QR-кодом для жюри

Чтобы члены жюри могли отсканировать QR-код с экрана проектора своими смартфонами и нажать **«Согласовать ремонт»** в прямом эфире:

1. В отдельном терминале запустите бесплатный туннель Cloudflare:
   ```bash
   cloudflared tunnel --url http://localhost:8000
   ```
2. Скопируйте выданный публичный адрес (например, `https://random-words.trycloudflare.com`).
3. В панели мастера CheckSTO откройте в левом меню **«Настройки публичной ссылки»**, вставьте этот URL и нажмите **«Сохранить»**.
4. Все QR-коды и ссылки для WhatsApp мгновенно переключатся на публичный адрес.
5. Перед началом выступления нажмите внизу сайдбара **«Сбросить демо-данные»**, чтобы вернуть чистую базу.
